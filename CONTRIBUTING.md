# Contribuer au projet

Merci de votre intéret pour le kit d'onboarding de l'équipe. Ce guide explique comment proposer une contribution.

## Avant de commencer

- Lire les [conventions de l'équipe](docs/conventions-equipe.md).
- S'assurer d'avoir un compte GitHub avec la double authentification.

## La marche à suivre

1. Créer une branche à partir de `main`, nommée par son intention (`ajout-...`, `correction-...`).
2. Faire ses modifications et les committer avec un message clair, à la forme `type: description`.
3. Pousser la branche, puis ouvrir une pull request vers `main`.
4. Décrire dans la pull request ce qu'elle apporte.
5. Après relecture, la pull request est fusionnée et la branche supprimée.

## Règles de base

- La branche `main` reste toujours stable : aucune modification directe.
- Un sujet par branche et par pull request.
- Les documents sont rédigés en Markdown.

## Signaler un problème

Pour signaler une erreur ou proposer une idée, ouvrir une issue en décrivant clairement le besoin.
