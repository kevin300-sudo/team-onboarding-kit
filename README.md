# team-onboarding-kit

Le kit d'onboarding de l'équipe : tout ce qu'un nouvel arrivant doit savoir pour devenir autonome, centralisé dans un seul endroit.

## Pourquoi ce dépôt

Les informations d'intégration étaient jusqu'ici éparpillées entre des mails, des messages et la mémoire des anciens. Ce dépôt les rassemble et en fait la source de référence, tenue à jour par l'équipe.

## Contenu

Le contenu s'enrichit au fil du temps. On y trouvera notamment :

- les procédures d'installation de l'environnement de travail,
- les conventions de l'équipe,
- les checklists du nouvel arrivant.

## Par où commencer

Si vous venez d'arriver dans l'équipe, parcourez ce README, puis suivez les documents dans l'ordre où ils seront listés ici.
