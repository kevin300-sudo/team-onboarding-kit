# Politique de sécurité

La sécurité de ce projet est importante. Cette page explique comment signaler une vulnérabilité.

## Signaler une vulnérabilité

Si vous découvrez une faille de sécurité, merci de ne pas ouvrir d'issue publique. Contactez plutot le responsable du dépot en privé, par email, en décrivant :

- la nature du problème,
- les étapes pour le reproduire,
- l'impact potentiel.

Un retour vous sera fait dans les meilleurs délais, puis une correction sera préparée avant toute divulgation publique.

## Versions prises en charge

La version en cours sur la branche `main` est la seule maintenue.

## Bonnes pratiques

- Ne jamais publier de secret (mot de passe, token, clé) dans le dépot.
- Signaler tout secret exposé par inadvertance pour qu'il soit révoqué.
