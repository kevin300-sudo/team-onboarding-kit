# Glossaire des termes GitHub

Les termes utiles pour travailler sur le dépôt de l'équipe.

**Dépôt (repository)** : l'espace qui contient les fichiers du projet et leur historique.

**Commit** : un enregistrement de modifications dans l'historique, avec un message.

**Branche (branch)** : une ligne de travail indépendante, qui part de la branche principale.

**main** : la branche principale, celle qu'on garde stable.

**Pull request** : une proposition de fusion d'une branche vers une autre, lieu de la relecture.

**Issue** : une fiche qui décrit une tache, une idée ou un problème.

**Merge** : la fusion d'une branche dans une autre.

**Clone** : une copie locale d'un dépôt distant, avec son historique.

**Fork** : une copie personnelle d'un depot, qui garde le lien avec l'original.
