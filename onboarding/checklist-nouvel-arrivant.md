# Checklist du nouvel arrivant

À suivre dans l'ordre pendant les premiers jours. Cocher chaque étape une fois faite.

## Comptes et accès

- [ ] Créer son compte GitHub.
- [ ] Activer la double authentification.
- [ ] Demander l'accès au dépôt de l'équipe.

## Poste de travail

- [ ] Installer Git et configurer son identité.
- [ ] Installer VS Code.
- [ ] Cloner le dépôt de l'équipe.

## Prise en main

- [ ] Lire la procédure d'installation.
- [ ] Lire les conventions de l'équipe.
- [ ] Faire une première contribution de test via une pull request.

## Pour aller plus loin

- [ ] Parcourir la documentation dans le dossier docs.
- [ ] Repérer qui contacter en cas de question.
